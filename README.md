# CSAlignNet: Pose-Robust Lightweight Finger Vein Recognition toward Strict Cross-Session Deployment

Official implementation of **CSAlignNet** (differentiable geometric alignment +
pseudo-session contrastive learning) plus the reproduced classical baselines
(Miura, Asaari) under the strict cross-session protocol.

> **Strict protocol.** The second session is invisible during training *and*
> hyper-parameter tuning. FV-USM: train/tune on Session-1 only
> (Gallery = S1, Probe = S2). UTFVP: three disjoint 3-train/1-test splits
> (seeds 42/43/44). Checkpoints are picked on a held-out 10% split of
> Session-1; Session-2 is evaluated once at the end.

## Results (from the paper)

| Method | FV-USM Rank-1 / EER | UTFVP Rank-1 / EER |
|---|---|---|
| Miura (reproduced) | 58.37 / 12.45 | 77.96±0.35 / 8.09±0.40 |
| Asaari (reproduced) | 74.90 / 9.20 | 69.17±2.39 / 9.82±0.36 |
| **CSAlignNet (ours)** | **90.66±0.81 / 3.27±0.41** | **94.63±0.32 / 2.21±0.24** |

Error attribution (3 seeds, 276±20 residual failures): 83.0±0.4% pose-recoverable,
0.5±0.2% photometric, 16.5±0.6% intrinsically ambiguous.

## Layout

```
csalignnet/            # main package: training + model
  train.py             # training entry (strict s1_only / joint ablation)
  evaluate.py          # strict cross-session evaluation (S1 gallery vs S2 probe)
  resnet18_baseline.py # strict-protocol ResNet-18 control
  vis_roi_pose_native.py
  logger.py  sam.py  cs_metrics.py
  pidanet/             # model + data modules
    cs_model.py        # CSAlignNet (AlignmentHead + Warper + backbone + heads)
    alignment.py  warping.py  session_head.py
    angular_margin.py  style_layers.py  domain_adv.py
    cs_dataset.py  augment.py  roi.py  cs_losses.py  cs_metrics.py
evaluation/            # analysis and figures
  pose_sweep.py        # fixed pose-robustness scan (rot / shift / combo)
  kfold.py             # intra-session control
  error_attribution.py # 3-seed residual-error attribution
  plot_attribution.py  # publication figure for the attribution
  load_model.py
baselines/             # reproduced classical methods (deterministic, no training)
  miura/   miura_baseline.py (FV-USM)   miura_utfvp.py (UTFVP)
  asaari/  asaari_baseline.py (FV-USM)  asaari_utfvp.py (UTFVP)
  shaheed/ shaheed_baseline.py (FV-USM) shaheed_utfvp.py (UTFVP)
figures/               # generated by evaluation/plot_attribution.py
checkpoints/           # put trained run folders here (see below)
```

The `LRFVNet` backbone is an external dependency (imported as `lrfvnet`).
Place it next to this repo (`../LRFVNet`) or set `LRFVNET_PATH`.
FV-USM / UTFVP datasets are not included; configure paths as below.

## Data paths

| Variable | Meaning | Used by |
|---|---|---|
| `FVUSM_ROOT` | FV-USM database root | `baselines/miura`, `baselines/asaari` |
| `UTFVP_ROI` | UTFVP per-class ROI images (`extractedvein`) | `baselines/*/​*_utfvp.py` |
| `UTFVP_SPLIT` | parent folder of the `UTFVP_3T1T*` split folders | `baselines/*/​*_utfvp.py` |
| `LRFVNET_PATH` | external `LRFVNet` repo location | all `csalignnet` / `evaluation` scripts |
| `CSALIGN_CKPT_DIR` | folder holding the three FT30 run folders | `evaluation/error_attribution.py` |

`train.py` / `evaluate.py` take `--session1_root` / `--session2_root` directly.

## Reproduce

```bash
# 1) Train CSAlignNet (Session-1 only; Session-2 never seen in training)
python csalignnet/train.py --session1_root <S1>/extractedvein \
  --session2_root <S2>/extractedvein --train_protocol s1_only \
  --epochs 160 --batch_size 64

# 30-epoch fine-tune (FT30)
python csalignnet/train.py --session1_root <S1>/extractedvein \
  --session2_root <S2>/extractedvein --train_protocol s1_only \
  --resume <ckpt> --epochs 30 --lr 2e-5 --run_name s1_only_ft30

# 2) Classical baselines (hyper-parameters calibrated on train only)
export FVUSM_ROOT=<path-to-FV-USM> UTFVP_ROI=<path-to-extractedvein> \
  UTFVP_SPLIT=<parent-of-UTFVP_3T1T*>
python baselines/miura/miura_baseline.py
python baselines/miura/miura_utfvp.py
python baselines/asaari/asaari_baseline.py
python baselines/asaari/asaari_utfvp.py

# 3) Error attribution (3 seeds) + figure
python evaluation/error_attribution.py --ckpt_dir checkpoints/cs_align
python evaluation/plot_attribution.py

# 4) Pose-robustness scan / intra-session control
python evaluation/pose_sweep.py --ckpt <ckpt> --data_root <root>
python evaluation/kfold.py
```

Expected layout of `checkpoints/cs_align` for step 3:

```
checkpoints/cs_align/
  cs_align_s1_only_mixstyle_cosface_ft30/      # seed 42
  cs_align_s1_only_mixstyle_cosface_ft30_s43/  # seed 43
  cs_align_s1_only_mixstyle_cosface_ft30_s44/  # seed 44
```

each holding `cs_align_best.pth` + `config.json`.

## Notes

- Classical baselines are deterministic (no training); UTFVP values are
  mean±std over the three splits.
- All trained-model numbers in the paper are three-seed mean±std.
